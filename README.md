# LR3_web_Bulich

Лабораторна робота № 3. Консольна програма на Node.js із пакетом `commander`.
Варіант 3: каталог на диску. Дані читаються з `data.json` (структура з ЛР1).

## Запуск

Потрібен Node.js 22.12 або новіший (цього вимагає commander 15).

```bash
npm install
node index.js --help
```

Те саме можна запускати через `npm start -- <команда>`, наприклад `npm start -- ls -a`.

## Глобальна опція

| Опція | Значення |
| --- | --- |
| `-f, --file <path>` | обов'язкова опція (`requiredOption`): шлях до JSON-файлу. Якщо не вказати, береться значення за замовчуванням `data.json`. Працює з будь-якою командою |

## Команди

Загальні можливості:

| Команда | Що робить |
| --- | --- |
| `list [-l, --limit <n>]` | стислий перелік усіх елементів (тип і шлях), не більше `n` |
| `show <path>` | один елемент цілком у форматі JSON |
| `field <path> <field>` | значення одного поля, зокрема вкладеного (`Object/best/object_count`) |

Можливості варіанта 3:

| Команда | Що робить |
| --- | --- |
| `ls [folder] [-a, --all]` | вміст папки; приховані елементи видно лише з `-a` |
| `size [path] [--exclude-hidden]` | сумарний розмір папки з усіма вкладеними елементами |
| `find <name> [-e, --exact] [-t, --type file\|folder]` | пошук за назвою в усьому дереві |

Шлях до елемента записується через `/`, без аргументу береться коренева папка.

## Приклади

```bash
node index.js list --limit 5
node index.js show summer_2007/picture1.jpg
node index.js field summer_2008/raw Object
node index.js ls summer_2007 -a
node index.js size Azov_2011 --exclude-hidden
node index.js find picture --type file
```

## Коди завершення

| Код | Значення |
| --- | --- |
| 0 | успіх |
| 1 | помилка виконання: файл не знайдено, некоректний JSON, немає елемента чи поля |
| 2 | неправильний виклик: невідома команда чи опція, немає аргументу, не число |
